# Code Of Conduct

MemoryWiki aims to be a useful, calm, and privacy-respecting open source
project.

## Expected Behavior

- Be respectful and concrete.
- Assume good intent, but keep technical claims evidence-based.
- Help newcomers reproduce issues safely.
- Redact secrets, private paths, and real memory content.
- Disagree by explaining tradeoffs, risks, and alternatives.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Posting someone else's private data or credentials.
- Pressuring maintainers or users to reveal private project memory.
- Repeated off-topic or bad-faith comments after maintainers redirect the
  conversation.

## Enforcement

Maintainers may edit, hide, or remove comments; lock heated discussions; close
non-actionable issues; or block accounts that harm the project community.

Security reports should follow `SECURITY.md`.
