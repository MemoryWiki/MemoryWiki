# Launch And Growth Plan

The target is not just publishing. The target is sustained discovery and trust.

## Positioning

MemoryWiki is a local-first memory wiki for AI agents: agent memory with
Markdown files, provenance, conflict logs, retrieval indexes, and MCP access.

Problem-first story:

> Agents forget project context. Cloud memory can be opaque. MemoryWiki keeps
> auditable agent memory in local files and lets MCP-capable tools recall it
> read-first.

## Star Milestones

- 0 to 100: README clarity, quickstart reliability, trusted early testers.
- 100 to 500: Show a sharp demo, collect issues, fix docs fast.
- 500 to 1500: Publish examples, integrations, and benchmark notes.
- 1500 to 3000: Build community proof through user stories, PRs, docs, and
  repeated feedback-driven releases.

## Launch Order

1. Quiet public GitHub launch.
2. Trusted review group.
3. Show HN or equivalent developer launch.
4. X/Twitter thread and short technical blog.
5. Targeted posts in local-first AI, MCP, PKM, and coding-agent communities.
6. Chinese posts on V2EX, 即刻, 知乎, 掘金, 开源中国, and a short video demo.

- Check Issues and Discussions daily.
- Label every report.
